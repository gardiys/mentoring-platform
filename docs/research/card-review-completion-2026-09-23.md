| Требование | Результат |
|---|---|
| Переход из подробной карточки к следующей | Предыдущая, следующая и пропуск без возврата к таблице. Очередь включает все ID по фильтрам, а не только текущую страницу. |
| После создания или отклонения сразу следующая | Создание, привязка дубля, отклонение и откладывание сохраняют решение и переходят дальше. Ошибка оставляет карточку на месте. |

| Быстро сравнить дубль | На широком экране форма и выбранный дубль рядом. Остальные совпадения — компактным списком. Ответ выбранного дубля отображается с Markdown; переключение не сбрасывает правки формы. |
| Завершение очереди | Отдельный экран завершения, возврат к очереди и обновление для новых карточек. |

## Дополнительные исправления при приёмке

- Обновление очереди заблокировано при сохранении обычного решения **и исправлений черновика**. Решения заблокированы во время загрузки нового снимка очереди. Повторное нажатие не отправляет дублирующую мутацию.
- Фокус окна не запускает автоматическое обновление подробной карточки, которое могло бы пересоздать форму и сбросить черновик. Предзагруженный ответ используется с коротким сроком свежести. Версия на сервере по-прежнему проверяется при изменении.
- При намеренном переходе с несохранёнными правками остаётся защита черновика. После успешного решения она не мешает автоматическому переходу.
- Вкладки прокручиваются в своей области и не расширяют страницу на мобильном экране. На узком экране панель действий не перекрывает редактор. Убраны повторяющаяся общая инструкция и большие отступы в тексте дубля.
- Персональный аудит Copilot выявил устаревшие ожидания в двух существующих тестах платформы: desktop scope уже разрешает GET списка установщиков и трёх допустимых downloads для обновлений. Тесты приведены к этому контракту, отрицательные проверки методов и неизвестных путей сохранены/расширены. Поведение авторизации не менялось; отдельные тесты продолжают проверять права пользователя на release endpoints.
