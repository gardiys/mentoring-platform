## Сопутствующее исправление отправки email

При запросе кода подтверждения в заявке Python → Go Brevo отклонял письма:

1. `missing_parameter`: передавалось пустое имя получателя. Теперь необязательное
   поле `name` отсутствует, если имя пустое.
2. `out_of_range`: ключ идемпотентности имел вид `legal-<UUID>`. Теперь используется
   UUID записи доставки, одинаковый при повторных попытках.

В локальном окружении worker перезапущен. После исправлений Brevo принял одно из
ранее запрошенных писем при штатной повторной попытке; запись перешла в `sent`.
Это подтверждает приём провайдером, а не получение письма почтовым клиентом.
Тест подтверждения email проверяет оба ограничения запроса, прохождение очереди
и последующее подтверждение кода. Письма с PDF-офертой также проверяют формат UUID.
