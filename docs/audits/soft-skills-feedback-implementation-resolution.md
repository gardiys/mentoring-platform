# Исправления по ревью Soft Skills

Основание: [soft-skills-feedback-implementation-review.md](soft-skills-feedback-implementation-review.md).
Изменения внесены локально; миграции данных и изменения `.env` не нужны.

## P1

| Замечание | Исправление |
| --- | --- |
| 3.1. Среднее худших примеров | Общий процент убран из UI и возвращается как `null` для совместимости. Вместо него — покрытие категорий. Категория усредняет оценки разных подтверждённых ответов: повтор одного навыка в одном ответе не увеличивает вес. Число наблюдений и оценённых ответов показано отдельно. Слабый пример сохраняется в `example_score` для практики; его оценка явно отделена от средней. |
| 3.2. Неиспользуемые strengths/growth | Поля удалены из схемы генерации, объединения сводок, ответа API и клиентских типов. Старые JSON продолжают читаться, эти поля отбрасываются. |
| 3.3. Неограниченная история | Максимум 30 последних разборов; сортировка по дате и ID, лимит до загрузки источников. Выбираются нужные поля вопросов/ответов/ревью и только реплики по ссылкам в наблюдениях. Сводки и рекомендации заново не собираются. `staleTime` — 60 секунд; действия инвалидируют кеш. API сообщает размер окна и наличие более ранних интервью. |
| 3.4. Полная сборка ради отметки | Отдельный загрузчик источников и общий `ground_dimensions`; `intelligence_detail` не вызывается. Права и проверка версии сохранены. Восстановление отклонённого вывода заново проверяет источник. |
| 3.5. Исчезновение отклонений | История возвращает наблюдение с `decision=rejected`; интерфейс показывает решение и ссылку на разбор, исключает его из сравнений и упражнений. На странице разбора отклонение видит и ученик; восстановление доступно только ментору/админу. |
| 3.6. Разные названия | Названия приходят из `SKILL_LABELS` через `communication_labels` и `dimension.name`. Отдельный фронтендовый словарь удалён. Все восемь категорий сохраняются. |
| 3.7. Одиночные «тренды» | Сравнение показывается только для двух и более разных интервью одного формата с оценкой того же навыка. Группы сортируются по последнему наблюдению. |
| 3.8. Обманчивые дельты | Дельты и заявление «три разбора подряд» удалены. Показаны последние шесть точек с датами и размером выборки; все списки идут от новых к старым, порядок задан явно и проверен тестом. |

## P2

- Цитаты короче 20 нормализованных символов не подтверждают наблюдение. Проверка выполняется при заземлении, поэтому один плохой пример не ломает целый AI-ответ и не вызывает дополнительного API-запроса. Требование добавлено в промпт.
- Проверка переформулировки учитывает распространённые единицы и русские числительные; десятичные запятая/точка эквивалентны. `20 человек → 20%` и `→ двадцать процентов` блокируются.
- Обрезанные цитаты, причины и задания получают многоточие; при наличии пробелов сохраняется граница слова.
- Уверенность AI показана у конкретного примера с пояснением её ограничений; количество наблюдений — у категории и точек истории.
- При отсутствии подтверждений общий абзац не копирует техническую сводку.
- Nullable-оценки проверяются одинаково; для старого отчёта без `candidate_questions` показывается пустое состояние.
- UI объясняет привязку выполненных упражнений к версии разбора и сброс нового набора после пересчёта.
- Версии промптов обновлены; технические части существующих сводок v7 остаются совместимыми. Общее число коммуникации больше не вычисляется при объединении сводок.

## Проверка

Автотесты покрывают источники цитат, усреднение десяти ответов с одним слабым примером, дедупликацию наблюдений, отсутствие общего процента, единицы/числительные/дроби, короткие цитаты, обрезание текста, права, версии, отклонение/восстановление, SQL-загрузку только ссылочных реплик, лимит истории до загрузки источников, порядок одинаковых дат, разные форматы интервью, исключение отклонённых упражнений и отображение покрытия/уверенности.

Результат: 100 backend-тестов и 13 frontend-тестов прошли; TypeScript, Ruff, Mypy для изменённых модулей feedback и `git diff --check` — без ошибок. После проверки фильтра JSON null отдельно повторены интеграционные тесты истории и действий.

Используется отдельная локальная тестовая БД `mentoring_test` и fake AI-провайдеры. Платные вызовы для проверки не нужны.

## Границы проверки

Цитата и её длина подтверждают наличие источника, но не педагогическую корректность вывода. Проверка чисел — консервативная эвристика: она не доказывает отсутствие выдуманных фактов, не покрывает все языки/формы единиц и может скрыть допустимую переформулировку сложного числительного. Оценки категорий остаются AI-наблюдениями по доступным ответам, а не измерением личности.

Слепая сверка 20 реальных интервью двумя независимыми интервьюерами не проводилась. Она остаётся отдельной работой для оценки качества выводов. История ограничена 30 последними разборами; более ранние наблюдения доступны на страницах отдельных разборов, постраничной загрузки старых наблюдений в этом блоке нет.
